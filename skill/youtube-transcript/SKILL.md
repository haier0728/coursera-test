# YouTube 逐字稿

這個技能附了一支現成的程式 `scripts/yt_transcript.py`，負責把 YouTube 字幕抓下來、整理成好讀的段落、存成 `.txt`。直接用它，不要自己重寫抓字幕的邏輯——它已經處理好各種網址格式、預設抓原文字幕（影片實際講的語言，人工字幕優先）、中文斷句與錯誤訊息。

## 步驟

1. **確認套件**：執行 `python3 -c "import youtube_transcript_api"`（Windows 用 `python`）。失敗就先 `pip install "youtube-transcript-api>=1.2,<2"`。

2. **抓逐字稿**：把檔案存到使用者給你的工作資料夾底下的 `YouTube逐字稿/`，方便日後集中查找。

   ```bash
   python3 <技能資料夾>/scripts/yt_transcript.py "<網址>" -o "<工作資料夾>/YouTube逐字稿"
   ```

   常用選項：
   - `--timestamps`：每行加 `[mm:ss]`，使用者想對照影片時間點時使用
   - `--lang zh-TW en`：不要原文、指定字幕語言優先順序
   - `--translate zh-Hant`：外語影片想直接看中文時，用 YouTube 自動翻譯
   - `--list-langs`：先查影片有哪些字幕
   - 多支影片可以一次給多個網址

   成功時程式會印出 `✅ 標題 → 檔案路徑`；失敗時印出 `❌` 加中文原因，退出碼為 1。

3. **回覆使用者**：使用者很可能是用手機在操作，看不到電腦上的檔案，所以回覆要讓使用者在手機上就能用：
   - 告訴使用者檔案存在哪裡（完整路徑）
   - 附上 3–5 點重點摘要，不用開檔也知道影片在講什麼
   - 問使用者要不要貼出全文、翻譯、或整理成特定格式（會議記錄、筆記、行動清單等）

   如果使用者一開始就說要摘要、翻譯或重點，讀取剛存好的 `.txt` 直接完成，不用再問。

## 常見錯誤

- **「YouTube 擋下了這個網路位址的請求」**：代表執行環境的網路被 YouTube 擋了（雲端主機或沙盒常見）。請使用者確認 Cowork 的網路設定允許連到 `youtube.com`，或在一般網路環境執行。
- **「作者關閉了字幕」/「沒有任何字幕」**：這支影片本身就沒有字幕可抓，誠實告訴使用者，不要猜測影片內容。
- **連不到網路 / 被公司防火牆擋**：說明情況，建議改用手機版（Termux）或換網路。
